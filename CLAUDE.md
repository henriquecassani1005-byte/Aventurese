# Regras de Operação do Second Brain (Kothon / Rubão V2.0)

* **Modo de Operação:** Ao analisar, ler ou criar notas neste vault, seja pragmático, calculista e focado em governança B2B.
* **Processamento de Inbox:** Quando o usuário pedir para "processar a Inbox", leia todos os arquivos em `00_Inbox`. Mova-os para o diretório correto dentro de `01_Projetos` baseado no contexto. Se houver tarefas, extraia-as e crie um bloco de "Next Actions".
* **Formatação:** Use sempre bullet points, tabelas e negrito para escaneabilidade. Elimine adjetivos vazios, introduções longas ou linguagem não executiva.
* **Gestão de Reuniões:** Sempre que sintetizar uma reunião, aplique o modelo de ATA (com Action Items e prazos). Modelo em `03_Recursos/Templates/Template_ATA.md`.
